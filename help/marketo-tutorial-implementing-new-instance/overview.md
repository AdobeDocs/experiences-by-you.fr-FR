# Conseils et astuces pour mettre en œuvre une nouvelle instance [!DNL Marketo Engage]

Bienvenue dans Adobe [!DNL Marketo Engage] ! La configuration d’une nouvelle instance est la première étape pour améliorer votre stratégie de marketing numérique avec l’automatisation du marketing. La clé d’une implémentation [!DNL Marketo Engage] réussie réside dans la documentation.

Cette série « Conseils et astuces pour la mise en œuvre d’une nouvelle instance » provient d’Adobe [!DNL Marketo Engage] Champions qui ont déjà conquis la mise en œuvre. Le tutoriel fournit des conseils détaillés aux nouveaux administrateurs pour gérer le projet d’implémentation de manière transversale et configurer les paramètres techniques indépendamment. Des rubriques sélectives accompagnent également des listes de contrôle et des modèles téléchargeables que vous pouvez personnaliser selon vos propres besoins, sans devoir repartir de zéro. Plongeons dans la sagesse de vos pairs !
